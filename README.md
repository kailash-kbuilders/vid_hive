# VidHive

A clean, minimal video player for Android and iOS. Plays the videos already on
your device — no account, no signup, no keys.

## Run

```
flutter pub get
flutter run
```

The `android/` folder is generated by the GitHub Actions workflow. To build
locally run `flutter create . --platforms=android` once (iOS needs macOS +
Xcode).

APK: push to `main`, or run the **Build APK** workflow manually.
